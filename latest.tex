该论文关注LLM驱动的agentic coding在SDLC中的可靠性问题, 指出规范质量成为自主交付的关键瓶颈. 作者提出Spec-Driven Agentic Development (SDAD)框架, 将意图捕获、机器可读specification、agentic synthesis与独立multi-agent verification结合, 并引入量化指标如Ambiguity Tax、Spec Fidelity和$\mathrm{TCI}_{\mathrm{agentic}}$(含repair multiplier $\phi$) 以支持治理. 通过对比Human-Agile与Agentic-SDAD范式, 论证agentic速度并未取消工程纪律, 而是将纪律前移至specification精度和显式checkpoint. 该方法在测试与验证流程中通过分离synthesis与release authority提升可靠性, 为AI-native SDLC提供了可落地的迁移蓝图.


\arxivwithtarget{2608.20342}{PrimeAgentOrchestrator: Memory-Primed Agent Spawning for Personal AI Infrastructure}{Myron Koch}\textbf{cs.AI}, cs.MA.

PrimeAgentOrchestrator (PAO) 针对LLM coding agent每次启动时上下文为空、先前知识全部丢失的问题, 在spawn新Claude Code实例时自动注入从用户个人数据库编译的相关记忆. PAO并行查询PostgreSQL实体观察库与Cloudflare Worker语义索引, 按后端专属retrieval策略融合结果, 并利用宿主agent的配置自动读取行为完成filesystem injection. 该系统管理完整agent lifecycle, 包括trust pre-seeding、readiness polling与自适应终端注入, 其四个月部署报告记录了三种上下文传递机制的演化及各自failure mode. 最终验证了桥接异构memory系统而非统一存储的工程可行性, 但揭示了reliability与延迟之间的实际tradeoff.

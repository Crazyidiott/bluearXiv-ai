Speculative Macro Commit for Faster Tool-Using Agents ⭐ 精选
Zeyu Liu, Souvik Kundu, Peter A. Beerel
cs.AI cs.MA
本文针对tool-using LLM agent在串行action-observation交互中累积高延迟的问题，提出Speculative Macro Commit (SMC)机制：由一个快速speculative drafter模型在隔离环境快照上持续预测并执行未来动作链，再通过从训练轨迹中挖掘的macro library匹配当前actor动作，若首步匹配则将其余预执行动作及观测整体提交至官方轨迹。采用Qwen3.5-27B INT4作为actor、Qwen3.5-4B作为drafter，在\(\tau^2\)-Bench Telecom子集上较Speculative Actions基线降低时延10.23\%，较串行执行降低18.59\%；在AppWorld上较串行执行降低44.9\%时延且仅损失少量任务完成率。该方法验证了宏提交机制可复用多步推测执行以提升agent效率，并兼顾可靠性。
Fresh Memory, Stale Plans: Dependency-Scoped Validation for Distributed LLM-Agent Memory ⭐ 精选
Evan Chen, Shiqiang Wang, Christopher G. Brinton
cs.AI

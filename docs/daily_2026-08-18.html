Agentao: A Governed Local-First Runtime for Tool-Using LLM Agents ⭐ 精选
Bo Jin, Qiang Jiao, Xin Tong
cs.AI cs.MA
Agentao 针对 LLM agents 在工具调用、状态修改和协议交互中面临的过度权限、弱审计、prompt injection 与 tool poisoning 等风险，提出了一个 host-controlled 的 local-first runtime。其核心方法是将模型生成的 action proposal 与 host 授权的 execution 分离，通过 host contract、permission-mediated tool system、memory 与 replay 等显式 runtime abstractions 构建分层架构。该系统不提供形式化安全保证，但使 permissions、state、protocol boundaries 与 execution traces 成为可检查的运行时抽象，从而提升 agent 的可治理性与可审计性。最终效果是在不牺牲工具调用能力的前提下，让 agents 更适用于 host 控制的本地环境。
Measuring Cross-Task Behavioral Consistency in Language Model Agents ⭐ 精选
Amritesh Banerjee, Pranil Raichura
cs.AI
本文针对语言模型Agent评估过度依赖success rate等结果指标、忽略行为一致性的问题，提出一种可量化的Behavioral Consistency Metric (BCM)。该方法训练一个模型从agent执行轨迹的行为特征预测任务成功与否，对每条轨迹生成feature-attribution vector，再计算同一agent系统内这些向量的平均两两相似度。基于约9000条来自六个LLM agent的软件工程轨迹，作者发现跨任务一致性与任务内一致性是可分离的两个维度，且两者均不能由success rate解释。BCM被定位为一种process-level reliability信号，可补充现有结果指标，但作者也明确指出了其适用条件。
